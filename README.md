## 🌟 Overview

**Villager AI** is a modern Minecraft mod designed to revamp villager artificial intelligence, giving villagers richer daily routines, improved decision-making, adaptive defenses, and smarter interactions with players and their surroundings.

---

## ✨ Features

- **🧠 Enhanced Villager AI**:
  - Smarter daily schedules and task coordination.
  - Improved pathfinding and threat reaction.
- **⚡ Dual Loader Support**:
  - Fully compatible with **Fabric** and **NeoForge** on Minecraft 26.3.
- **🛠️ Extensible Architecture**:
  - Clean multiloader setup with shared logic in `common`.

---

## 📦 Compatibility & Requirements

- **Minecraft**: 26.3
- **Mod Loaders**:
  - Fabric (requires Fabric Loader & Fabric API)
  - NeoForge
